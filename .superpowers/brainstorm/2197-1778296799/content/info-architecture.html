各页面职责

🏠 首页 · 性格卡片
展示你的运动性格状态（活力/枯萎）、今日是否已运动、快速记录入口、性格进化提示。是情感绑定的核心。
📅 运动日历
GitHub 风格热力图，显示全年运动轨迹。连续天数、最长记录、本周完成度一目了然。社交契约也在这里展示。
🏅 徽章墙
已解锁/未解锁徽章展示，按分类（频率/耐力/多样/社交）组织。显示距离下一枚徽章的进度条。
👥 运动圈
好友运动动态 Feed、实时运动提示、社交契约（本周承诺）。发布运动记录后自动推送。
📊 周报/月报（非固定页面，定时生成）
每周日晚自动生成，含运动天数、性格变化、徽章进度、好友排名。一键生成精美分享图，传播到朋友圈/小红书。
