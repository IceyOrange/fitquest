技术方案与数据流

MVP 阶段保持简洁，渐进式迭代

推荐技术栈

前端
框架：React + TypeScript
样式：Tailwind CSS
动画：Framer Motion
图表：Recharts
理由：组件化开发 + 动画效果丰富 + 快速迭代
后端
运行时：Node.js
框架：Express / Fastify
数据库：PostgreSQL
ORM：Prisma
理由：全栈 JS + 类型安全 + 关系型数据适合社交
部署
前端：Vercel
后端：Railway / Render
数据库：Supabase
理由：免费额度足够 MVP，一键部署
数据接入
V1：手动记录运动
V2：Keep API 同步
V3：Apple Health / 微信运动
理由：渐进式接入，降低冷启动门槛

核心数据流

1. 记录运动 用户手动输入 → 写入 Workout 表
↓
2. 触发计算 检查徽章解锁条件 + 更新连续天数 + 重算性格能量
↓
3. 生成事件 新徽章 / 性格变化 / 连续天数 → 推送到运动圈 Feed
↓
4. 社交传播 好友看到动态 → 点赞/见证 → 触发对方的多巴胺反馈
↓
5. 周期汇总 每周日晚 → 生成报告卡 → 用户分享 → 带来新用户
