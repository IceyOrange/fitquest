# FitQuest — 游戏化运动激励工具 产品设计文档

> 日期：2026-05-09
> 状态：已确认

## 1. 产品定位

**目标用户**：大学生
**核心问题**：运动健身缺乏持续动力，难以坚持锻炼计划
**解决方案**：通过游戏化性格系统 + 社交 + 成就徽章，将延迟的运动回报转化为即时反馈，提升运动频率

**产品形态**：Web 应用（移动端优先响应式设计）
**视觉风格**：轻松可爱风（类似小红书 / NesCoffee 的亲和感）

## 2. 行为驱动模型

产品设计基于 Nir Eyal 的 Hook 模型，围绕四个行为驱动引擎构建：

### 驱动引擎一：情感绑定（Tamagotchi 效应）
- 运动性格有「能量状态」，随运动频率变化
- 坚持运动 → 性格「活力满满」（鲜艳、灵动）
- 停止运动 → 性格「枯萎/沉睡」（褪色、低落）
- 重新运动 → 性格「觉醒」（特殊回归动画）
- 用户对性格产生情感投资，不愿看到它枯萎

### 驱动引擎二：损失厌恶（连续链条 + 社交契约）
- GitHub 风格运动热力图，可视化全年运动轨迹
- 连续天数计数器，断裂会归零
- 社交契约：每周公开宣布运动目标，好友可「见证」
- 完成契约获得特殊徽章 + 庆祝动画
- 未完成时性格显示「待兑现」状态

### 驱动引擎三：社会认同（FOMO 触发）
- 实时运动感知：「此刻有 N 位好友正在运动」
- 好友运动动态自动推送至 Feed
- 周报对比：「你的运动天数超过了 X% 的好友」

### 驱动引擎四：好奇心缺口（变量奖励）
- 性格会进化：每次运动后好奇「今天会变吗？」
- 徽章解锁的不可预测性
- 好友点赞/见证的社交反馈

## 3. 信息架构

精简为 3 个核心页面：

### 3.1 首页（核心触发器）

首页是用户每次打开的「5 秒说服链」，按视线顺序组织：

1. **性格能量卡片**（情感触发）
   - 运动性格角色 + 当前状态（活力/渴望/枯萎/进化）
   - 能量百分比进度条
   - 状态描述文案（如「能量正在衰减...」）

2. **连续打卡状态**（危机感）
   - 连续运动天数 + 火焰图标
   - 7 日方块进度条
   - 提示语：「今天不运动就会断链！」

3. **好友动态摘要**（社会压力）
   - 今日已运动好友头像
   - 最新一条好友运动动态
   - 性格排名提示

4. **徽章进度预告**（奖励预告）
   - 距离下一枚徽章的进度条
   - 差几次解锁的明确提示

5. **记录运动按钮**（行动出口）
   - 全宽紫色渐变大按钮
   - 提示：「运动后性格能量将恢复至 100%」

### 3.2 运动圈（社交页）

- 顶部：本周社交契约进度条
- Feed 动态流：
  - 运动打卡记录
  - 徽章解锁事件
  - 性格进化事件
- 每条动态支持：点赞、评论、「见证」

### 3.3 我的（个人页）

- 完整徽章墙（4 系列铜银金 + 传说）
- 年度运动热力图（完整版）
- 运动历史记录
- 性格测试重做入口
- 账号设置

### 3.4 报告卡（定时生成，非固定页面）

- 每周日晚自动生成
- 内容：性格状态 + 运动天数 + 总距离 + 好友排名 + 徽章进度
- 精美渐变卡片样式
- 一键生成分享图（朋友圈/小红书）

## 4. 运动性格系统

### 4.1 性格分类维度

基于 4 个可量化的运动行为维度交叉生成：

| 维度 | 数据源 | 光谱 |
|------|--------|------|
| 时间偏好 | 运动记录时间分布 | 晨型 ←→ 夜型 |
| 强度偏好 | 运动类型 + 时长 | 高强度 ←→ 低强度 |
| 频率模式 | 每周运动天数方差 | 稳定规律 ←→ 爆发集中 |
| 运动多样性 | 运动类型种类数 | 单一专精 ←→ 多样探索 |

### 4.2 八种运动性格

| 性格 | 维度特征 | 标语 |
|------|----------|------|
| 🌅 黎明行者 | 晨型 · 稳定 · 中高强度 | "太阳还没醒，我已经在路上了" |
| 🦉 夜猫铁人 | 夜型 · 高强度 · 爆发 | "夜深了，铁馆才是我的主场" |
| 🔥 燃脂战士 | 高强度 · 稳定 · 专精 | "不流汗不痛快" |
| 🧘 禅意行者 | 低强度 · 稳定 · 多样 | "运动是和自己对话" |
| 🌊 自由浪人 | 爆发型 · 多样 · 随性 | "想动就动，不想就躺着" |
| 🎯 精准猎手 | 规律 · 专精 · 计划型 | "每一练都在计划之中" |
| 🦋 全能蝶变 | 多样 · 均衡 · 全能 | "什么都会一点，什么都爱" |
| 🏔️ 马拉松之魂 | 耐力型 · 长时 · 坚韧 | "不在于快，在于不停" |

### 4.3 性格能量状态

| 状态 | 条件 | 能量 | 视觉效果 |
|------|------|------|----------|
| ✨ 活力满满 | 近 3 天有运动 | 80-100% | 鲜艳、动画灵动 |
| 😴 渴望运动 | 停 2-3 天 | 40-79% | 颜色变淡、微动 |
| 🥀 枯萎中 | 停 4 天以上 | <40% | 灰度、静止、悲伤 |
| ⚡ 进化中 | 数据模式变化中 | — | 闪光、粒子特效 |

### 4.4 性格生成规则

**冷启动（新用户）：**
- 6 道趣味情景选择题
- 情景化题目如「期末考试周你会...」
- 3 分钟完成，生成初始性格
- 结果可立即分享

**数据驱动（运动 ≥ 10 次后激活）：**
- 系统自动分析 4 个维度数据
- 以 14 天为滑动窗口重新计算
- 性格变化时播放进化动画
- 变化通知推送到运动圈 Feed

## 5. 徽章与成就系统

### 5.1 徽章系列

**坚持之心（频率系列）— 损失厌恶驱动**
| 等级 | 条件 |
|------|------|
| 🥉 铜 | 连续运动 7 天 |
| 🥈 银 | 连续运动 14 天 |
| 🥇 金 | 连续运动 30 天 |
额外：月度运动 10/15/20 天、季度全勤

**里程之魂（耐力系列）— 积累驱动**
| 等级 | 条件 |
|------|------|
| 🥉 铜 | 累计跑步 10km |
| 🥈 银 | 累计跑步 50km |
| 🥇 金 | 累计跑步 100km |
额外：累计运动 10h/50h/100h

**探索之翼（多样系列）— 好奇心驱动**
| 等级 | 条件 |
|------|------|
| 🥉 铜 | 尝试 3 种运动 |
| 🥈 银 | 尝试 5 种运动 |
| 🥇 金 | 尝试 8 种运动 |
额外：解锁 2/4/8 种性格类型

**契约之证（社交系列）— 社会认同驱动**
| 等级 | 条件 |
|------|------|
| 🥉 铜 | 完成首份社交契约 |
| 🥈 银 | 连续 4 周完成契约 |
| 🥇 金 | 获见证 20 次 |
额外：带动好友运动、好友互见证

### 5.2 传说徽章（隐藏成就）
- 不显示解锁条件
- 激发探索欲和炫耀欲
- 示例条件（不向用户展示）：全年运动 300 天、拥有全部 8 种性格、社交契约完成率 100%

## 6. 社交功能

### 6.1 运动圈 Feed
- 好友运动动态实时推送
- 动态类型：运动打卡、徽章解锁、性格进化
- 互动方式：点赞、评论、「见证」
- 「见证」是核心社交动作，替代普通点赞，赋予仪式感

### 6.2 社交契约
- 用户每周公开宣布运动目标（如「本周运动 4 次」）
- 好友可点击「见证」表示关注
- 完成后获得特殊庆祝动画 + 契约徽章进度
- 未完成时性格显示「待兑现」状态（非惩罚，而是激励）

### 6.3 报告卡
- 每周日晚自动生成
- 精美渐变卡片设计
- 包含：性格状态、运动天数、总距离、好友排名、徽章进度提示
- 一键生成分享图，支持保存到本地或直接分享

## 7. 数据录入

### V1（MVP）：手动记录
- 选择运动类型（跑步/健身/游泳/瑜伽/骑行/篮球等）
- 输入时长和可选距离
- 一键提交，低摩擦

### V2：Keep API 同步
- 对接 Keep 开放 API
- 自动同步用户运动记录

### V3：扩展数据源
- Apple Health
- 微信运动

## 8. 技术方案

### 8.1 技术栈

| 层级 | 选择 | 理由 |
|------|------|------|
| 前端框架 | React + TypeScript | 组件化开发，类型安全 |
| 样式 | Tailwind CSS | 快速实现可爱风格 |
| 动画 | Framer Motion | 性格状态动画、徽章解锁效果 |
| 图表 | Recharts | 热力图、报告卡数据可视化 |
| 后端框架 | Node.js + Express | 全栈 JS |
| 数据库 | PostgreSQL | 关系型数据适合社交场景 |
| ORM | Prisma | 类型安全，迁移方便 |
| 部署 | GitHub + Vercel | 前端一键部署，CI/CD 集成 |
| 数据库托管 | Supabase | 免费额度足够 MVP |

### 8.2 核心数据模型

**User（用户）**
- id, name, avatar
- personality_type（当前性格）
- personality_energy（能量值 0-100）
- streak_days（连续天数）
- longest_streak（历史最长连续）

**Workout（运动记录）**
- id, user_id
- type（运动类型）, duration（时长）, distance（距离，可选）
- recorded_at（时间戳）
- source（数据来源：manual / keep / apple_health）

**Badge（徽章）**
- id, user_id
- type（系列）, tier（铜/银/金）
- unlocked_at（解锁时间，null 表示未解锁）
- progress（当前进度百分比）

**Contract（社交契约）**
- id, user_id
- week_start（周一日期）
- target_count（目标次数）
- actual_count（已完成次数）
- witness_ids（见证人列表）

**Friendship（好友关系）**
- id, user_id, friend_id
- created_at

**FeedItem（动态）**
- id, user_id
- type（workout / badge_unlock / personality_evolve）
- content（JSON，动态内容）
- created_at

### 8.3 核心数据流

```
记录运动 → 写入 Workout
         → 检查徽章解锁条件（遍历所有未解锁徽章）
         → 更新 streak_days
         → 重算 personality_energy
         → 若运动次数 ≥ 10，以 14 天窗口重算性格类型
         → 生成 FeedItem（如有徽章解锁/性格变化）
         → 推送到好友 Feed
```
